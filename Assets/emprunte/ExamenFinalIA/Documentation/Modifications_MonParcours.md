# MonParcours

Le tracé suit le schéma fourni : remonter la bande jaune gauche, franchir le passage du haut, descendre la bande bleue centrale, franchir le passage du bas, puis remonter la bande jaune droite vers l'arrivée.

Chaque bande mesure 5 × 25 unités et conserve ses cinq plateformes d'origine. Les intervalles mesurent 2,25 unités à gauche et 5,625 à droite. Les passages, de 4,2 unités de profondeur, touchent les bords des bandes. Les raccords ont été vérifiés dans Unity.

Le prefab Synty SM_Gen_Env_Water_Plane_01 couvre 800 × 800 unités, à Y = −1,25 sous les plateformes. La caméra présente une vue d'ensemble. Les pièces, le danger, l'anneau, les caisses, les plateformes latérales et le décor suivent leur bande. Les éléments d'interface de l'utilisateur sont conservés.

Objets présents avant l'opération conservés : 65/65. Prefabs Synty : 61/61 (100,0 %). Scripts manquants : 0.

La scène reste une composition statique : aucun script de gameplay n'a été ajouté. Les flèches sont des prefabs Synty avec un matériau blanc personnalisé. La disposition, les matériaux ajoutés et les modifications ont été préparés avec OpenAI Codex le 9 novembre 2026. Modèles : Synty Studios, Polygon Starter et Polygon Generic. L'assistance doit être citée selon les consignes du cours.
